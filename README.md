# YouTube Lite Popup Blocker

## Install in Brave or Chrome

1. [Download the extension](https://github.com/ChristopherManzi/youtube-lite-popup-blocker/archive/refs/heads/main.zip).
2. Extract the ZIP file to a folder you want to keep.
3. Open your browser's extensions page:
   - **Brave:** enter `brave://extensions` in the address bar.
   - **Chrome:** enter `chrome://extensions` in the address bar.
4. Turn on **Developer mode** in the top-right corner.
5. Click **Load unpacked**.
6. Select the **extension** folder inside the extracted repository. This is the folder containing `manifest.json`.
7. Reload any open YouTube tabs.

The extension runs automatically when you visit YouTube. Keep the extracted folder in its original location after installation.

## Update

1. Download and extract the latest version.
2. Replace the contents of your installed **extension** folder with the updated files.
3. Open `brave://extensions` or `chrome://extensions`.
4. Click the reload button on the **YouTube Lite Popup Blocker** card.
5. Reload your YouTube tabs.

## Disable or remove

Open `brave://extensions` or `chrome://extensions` and find **YouTube Lite Popup Blocker**. Use its toggle to disable it, or click **Remove** to uninstall it. Reload your YouTube tabs afterwards.
